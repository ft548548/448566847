# 演示页说明

打开 `demo/index.html` 即可（双击或拖进浏览器），**不需要启动任何服务**，不发任何网络请求。

## 页面包含

1. **身份切换**：学生 / 教师 / 管理员，切换后权限表判定结果随之变化；
2. **权限差异**：六条代表性权限点，逐条写出「服务端判定依据」（与 `docs/platform/permissions.md` 一致）；
3. **一条联动流程**：考试通过 → 准入投影 → 发布招募 → 学生报名 → 审批入队，标注权威平台与事件类型；
4. **事件封套**：规范 §9.3 的 10 字段示例；
5. **响应信封对比**：左栏规范形状，右栏是 `GET /api/system/setting` 的实测返回（脱敏）。

## 必须知道的边界

| 项       | 说明                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 数据来源 | **全部硬编码在页面里**，不是真实接口返回；页头与页脚都有「演示数据」标记            |
| 身份     | 模拟身份，不代表已接入 SSO。真实系统用请求头 `token`，见 DV-01                      |
| 事件     | DooTask 本期**不生产事件**（DV-11），封套只用于确认字段形状                         |
| 流程     | 五步是**契约层面的示意**，不代表 DooTask 已有里程碑/验收模型（详见字段映射文档 §4） |
| 教师角色 | DooTask 没有 `teacher` 角色，演示里的教师权限按「普通成员 + 恰为招募发布者」推导    |

## 字段命名原则

页面中的字段名一律引用规范契约（`eventId`、`sourcePlatform`、`code`、`requestId` 等），
不另造字段。DooTask 内部字段（`userid`、`project_id`）只在 `data-dictionary-mapping.md`
里作为映射源出现。
